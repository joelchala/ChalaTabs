ChalaTabs

Gestor de pestañas en espacios de trabajo (Workspaces), suspensión inteligente de pestañas inactivas para ahorrar RAM y buscador instantáneo para Chrome y Microsoft Edge.

  • Código fuente de la extensión: src/
  • Compilación lista para cargar descomprimida: dist/build/ChalaTabs.chromium/
  • Pruebas automatizadas: node tests/verify.mjs
  • Repositorio oficial: github.com/joelchala/ChalaTabs
